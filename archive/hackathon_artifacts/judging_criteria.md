# HackTheAI – Judging Criteria

## Round 1

| Category | Marks | Description |
|----------|-------|-------------|
| UI/UX Prototype | 10 | Show planned flow & design (Figma / Adobe XD) |
| ER Diagram | 10 | Database design, normalized schema, relationships |
| End-to-End Activity Diagram | 10 | Clear workflows, data flow, architecture |
| UI/UX Design | 20 | Intuitive, smooth, visually appealing, consistent |
| Features | 20 | Small & big features; quality, relevance, depth |
| Idea Usability & Uniqueness | 20 | Real usefulness, originality, new perspective |
| Code Quality & Documentation | 5 | Modular, scalable, well-documented code |
| SmythOS API Usage | 5 | Innovative use of SmythOS APIs |

## Round 2

| Category | Marks | Description |
|----------|-------|-------------|
| Feature Implementation | 10 | Features implemented correctly & innovatively |
| Customization & Explanation | 10 | Ease of customization; explanation clarity |

## Round 3

| Category | Marks | Description |
|----------|-------|-------------|
| Demonstration | 10 | Clear, effective live demo |
| Presentation | 5 | Logical, engaging, complete presentation |
| Feature Innovation | 5 | Innovative, stand-out features |
| Usability & UX | 5 | Easy for end-users; tangible benefits |
| UI/UX Quality | 5 | Polished, consistent, visually appealing, accessible |

---

**Hackathon Notes:**
- Modular backend and normalized JSON outputs can increase scores for **Features, Usability, and API usage**.  
- ER diagrams, architecture diagrams, and well-documented endpoints → improve **Prototype & Documentation** marks.  
- Using agents as APIs and linking actions to risk IDs shows **innovation & real-world applicability**.
