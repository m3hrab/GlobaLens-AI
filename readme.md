# 🌐 GlobaLens AI

**Real-time, multi-agent AI platform for global supply chain risk monitoring and predictive insights.**  
Built for **HackTheAI 2025** using **SmythOS Flow Builder**, **FastAPI**, and **Next.js**.

GlobaLens AI provides **instant, actionable risk intelligence** for global supply chains.

predict upcoming disruptions, and recommend mitigation strategies—helping decision makers reduce losses and act fast.
